## 🎯 Repository Purpose

- **Mathematical Foundations:** Build solid intuition in linear algebra, multivariable calculus, and probability/statistics through code and visual derivations.
- **Hands-on Implementation:** Complete lab assignments and coding exercises end-to-end.

## 📚 Curriculum & Tracks

### 1. 📐 Mathematics for Machine Learning and Data Science (M4ML)
*DeepLearning.AI — Foundational Mathematical Intuition*

- [ ] **Course 1: Linear Algebra for Machine Learning and Data Science**
  - Vectors, systems of linear equations, matrices, vector spaces, eigenvalues & eigenvectors, SVD, and geometric transformations.
- [ ] **Course 2: Calculus for Machine Learning and Data Science**
  - Derivatives, gradients, directional derivatives, partial calculus, optimization, Hessian matrices, and gradient descent mechanics.
- [ ] **Course 3: Probability & Statistics for Machine Learning and Data Science**
  - Discrete and continuous distributions, conditional probability, Bayes' theorem, maximum likelihood estimation (MLE), central limit theorem, and hypothesis testing.

---

### 2. 🤖 Machine Learning Specialization (MLS)
*Stanford Online & DeepLearning.AI*

- [ ] **Course 1: Supervised Machine Learning: Regression and Classification**
  - Linear regression, logistic regression, cost functions, gradient descent, vectorization, and L1/L2 regularization.
- [ ] **Course 2: Advanced Learning Algorithms**
  - Multi-layer perceptrons (MLPs), activation functions, multi-class classification, bias/variance trade-offs, decision trees, random forests, and XGBoost.
- [ ] **Course 3: Unsupervised Learning, Recommenders, Reinforcement Learning**
  - K-means clustering, anomaly detection, PCA, collaborative filtering, content-based filtering, and deep Q-learning.

---

### 3. 🔬 Deep Learning Specialization (DLS)
*DeepLearning.AI*

- [ ] **Course 1: Neural Networks and Deep Learning**
  - Vectorized forward & backpropagation, deep $L$-layer architectures, activation mechanics.
- [ ] **Course 2: Improving Deep Neural Networks: Hyperparameter Tuning, Regularization and Optimization**
  - Initialization strategies, Dropout, Batch Normalization, Adam / RMSprop optimizers.
- [ ] **Course 3: Structuring Machine Learning Projects**
  - Train/Dev/Test splits, distribution mismatch, error analysis, transfer and multi-task learning.
- [ ] **Course 4: Convolutional Neural Networks (CNNs)**
  - Convolutions, pooling, ResNets, object detection (YOLO), FaceNet, neural style transfer.
- [ ] **Course 5: Sequence Models**
  - RNNs, GRUs, LSTMs, Attention mechanisms, Transformer architectures.
